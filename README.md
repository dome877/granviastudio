# Gran Vía Studio, web stranica

Statična stranica (HTML, CSS, malo JavaScripta), bez build koraka.

## Objava na GitHub Pages
1. Napravite novi repozitorij na GitHubu (npr. `granviastudio`).
2. Učitajte cijeli sadržaj ove mape (index.html, css/, js/, img/) u korijen repozitorija.
3. Settings → Pages → Source: "Deploy from a branch", grana `main`, mapa `/ (root)`.
4. Za vlastitu domenu (granviastudio.com.hr) upišite je u Settings → Pages → Custom domain.
